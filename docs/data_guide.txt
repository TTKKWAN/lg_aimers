배포용 데이터 구조]

open.zip

	├── baseline_submit.zip : 베이스라인 코드 기반 리더보드 제출 파일(zip) (참고용)

	├── data/

	│ 			├── train.csv : 학습 입력 및 정답 데이터 (1,475,092행 x 49컬럼)

	│ 			├── test.csv : 평가 입력 데이터 (형식 확인용 5건 샘플, 48컬럼)

	│ 			├── sample_submission.csv : 제출 양식 파일 (형식 확인용 5행 x 2컬럼)

	│ 			└── trackman_history.csv : 2019~2024년 Trackman 과거 로그 (1,793,078행 x 30컬럼)

	└── data_description.md : 데이터 설명서



※ `test.csv`는 배포용 데이터에 형식 확인용 샘플 5건만 포함됩니다. 실제 평가 데이터는 245,789행으로 비공개이며, 제출용 파일(zip)을 리더보드 평가에 제출하면 평가 서버에서 동일한 경로와 동일한 컬럼 구조의 실제 평가 데이터로 교체되어 처리됩니다.

※ `sample_submission.csv` 역시 형식 확인용 5건 샘플입니다. 실제 평가 시에는 평가 서버의 `test.csv` 245,789행 수와 동일한 제출 양식을 생성해 제출해야 합니다.
